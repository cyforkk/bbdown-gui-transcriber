# 功能总和文档

## 标准 GitHub 项目结构

### 文件/目录

- `src/bbdown_gui/`：应用源码包。
- `tests/`：单元测试。
- `scripts/`：打包脚本。
- `docs/`：功能和问题记录文档。
- `release/`：发布文件。

### 处理结果

已将原根目录脚本整理为标准 `src` 布局：

- `src/bbdown_gui/app.py`
- `src/bbdown_gui/downloader.py`
- `src/bbdown_gui/transcriber.py`

测试移动到：

- `tests/test_app.py`
- `tests/test_downloader.py`
- `tests/test_transcriber.py`

## 同目录 BBDown 检测

### 功能说明

采用方案 B：不把 BBDown 打进 exe 内部，但支持用户把 `bbdown.exe` 放到 release 同目录。

### 检测顺序

1. exe 同目录 `bbdown.exe`。
2. 源码运行时项目根目录 `bbdown.exe`。
3. 系统 PATH 中的 `bbdown`。
4. 用户手动选择。

## 下载功能

支持收藏夹/单视频下载，音频/视频二选一，停止下载，隐藏 CMD 窗口。

## 转文字功能

支持音频和 `.mp4` 视频转文字。视频转文字识别的是音频流，不做 OCR。支持文件夹批量转换，模型只加载一次。

## 打包功能

通过 `uv run python scripts/build_exe.py` 打包新版 GUI。当前 release exe 包含 Faster-Whisper 相关依赖，大小约 91.58 MB，不包含 BBDown 本体。
